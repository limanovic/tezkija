## Notes for the test track

The parts that only show themselves over days:

- A reminder set for tomorrow morning actually arrives, and on time. On
  Xiaomi/Oppo/Vivo/Huawei this is where autostart and battery optimisation
  bite — Settings offers both system screens.
- A time set to **In order** advances by one portion per reminder and does not
  jump or repeat after the app has been closed for a few days.
- Several **In order** times split one pass across the day — 09:00 gets #1,
  13:00 gets #2, 18:00 gets #3 — rather than each starting over at 2:42.
- A **Random** time never moves that progression.
- Tapping a reminder opens exactly the ayahs it showed.
- The "Poslaniku" badge appears on the 106 flagged ayahs and nowhere else.
